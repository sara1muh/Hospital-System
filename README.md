# Hotel Booking System

A Java-based Hotel Booking System designed to manage hotel reservations, guests, rooms, and staff information through a simple and organized system.

## 📌 Project Overview

The **Hotel Booking System** is a Java application developed to demonstrate the implementation of object-oriented programming concepts and data structures in a hotel reservation environment.

The system provides a structured way to manage hotel-related information, including guests, rooms, reservations, and staff.

## ✨ Features

* 🏨 Manage hotel information
* 🛏️ Manage room information
* 👤 Manage guest information
* 📅 Create and manage reservations
* 👨‍💼 Manage staff information
* 📋 Manage reservations using data structures
* 🔗 Implementation of a singly linked list
* 📦 Implementation of a linked-list-based queue

## 🛠️ Technologies Used

* **Java**
* **NetBeans IDE**
* **Object-Oriented Programming (OOP)**
* **Data Structures**
* **Singly Linked List**
* **Queue**

## 🚀 How to Run

1. Download or clone the repository.
2. Open **NetBeans IDE**.
3. Select **File → Open Project**.
4. Select the `HotelBookingSystem` project folder.
5. Build and run the project.

The main objectives of this project are:
